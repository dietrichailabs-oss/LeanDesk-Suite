# LeanDesk Suite Roadmap

## Current — 0.8.0 functional preview

Writer, Sheets, Slides, Notes, Draw, Tasks, Calendar, and Contacts are all available for testing in one suite.

## Next validation stage

- Windows EXE, installer, file-association, install, update, and uninstall acceptance
- Writer page layout, tables, embedded images, headers, footers, links, and page numbers
- Expanded DOCX round-trip formatting
- Sheets selection ranges, formatting, charts, freeze panes, sorting, and filtering
- Slides movable objects, shapes, layouts, transitions, and richer PPTX mapping
- Notes attachments and notebook export
- Draw connectors, snapping, grouping, layers, and improved arrow export
- Shared template gallery and print-preview service

## Later release goals

- Faster installed `onedir` package while retaining one installer and one launcher
- Accessibility and keyboard-navigation audit
- Update-manifest publishing and installed-runtime lifecycle validation
- Linux compatibility audit after Windows behavior is stable

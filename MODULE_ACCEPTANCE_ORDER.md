# Recommended Acceptance Order

1. **Writer** — ribbon visibility, spell checking, personal words, line spacing, save/open, DOCX, and PDF
2. **Sheets** — cell editing, formulas, multiple worksheets, CSV, and XLSX
3. **Slides** — slide editing, themes, notes, images, presenter mode, and PPTX
4. **Notes** — editing, Markdown preview, notebooks, tags, search, pinning, and persistence
5. **Draw** — shapes, movement, selection, colors, native save, SVG, and PNG
6. **Tasks** — add/edit/complete/delete and persistence
7. **Calendar** — month navigation and event persistence
8. **Contacts** — add/edit/search/delete and persistence
9. **Installer** — install, optional associations, shortcuts, update, and uninstall

Actual interface screenshots are under `docs/screenshots` and combined in `docs/LeanDesk_Suite_0.8.0_UI_Overview.png`.

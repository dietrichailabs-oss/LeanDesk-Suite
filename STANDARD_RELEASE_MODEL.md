# Dietrich AI Labs Standard Release Model

LeanDesk Suite follows the standard public Windows release model:

- custom application, installer, shortcut, and uninstall icon
- one-file windowed EXE
- current-user Inno Setup installer
- EULA acceptance during setup
- Start Menu shortcut and optional desktop shortcut
- normal Windows Installed apps entry
- reusable self-signed Dietrich AI Labs certificate where supported
- signature report and SHA256 checksums
- portable, installer, and complete ZIP packages
- GitHub-ready Release Ready folder
- README, changelog, license, notices, artwork, and tests
- local user data preserved during uninstall

Authoritative production path:

`/updates/leandesk.json`

Authoritative public URL:

`https://www.dietrichailabs.com/updates/leandesk.json`

The example JSON beside this file is a deployment template only. It is **not** a live-release authorization. Do not publish or advance `latest_version` until independent QA approves the exact immutable public artifact, that artifact is uploaded to the official Dietrich AI Labs destination, and its exact SHA-256 is entered where applicable.

The LeanDesk application treats the manifest strictly as data, accepts only the fixed HTTPS manifest endpoint, and accepts release/download links only on the official `www.dietrichailabs.com` HTTPS host and approved path families.

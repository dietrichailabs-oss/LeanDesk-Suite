# LeanDesk Suite 0.8.0 UI Acceptance Checklist

## Writer

- File menu contains New, Open, Save, Save As, PDF export, and Print
- Home ribbon groups are fully visible without clipped descriptive text
- Italic button uses a clearly slanted I
- Line-spacing and paragraph-spacing controls work
- Review tab runs spell checking and personal dictionary management
- Right-clicking an underlined misspelling shows suggestions

## Sheets

- Cell editing, formula bar, formulas, worksheet tabs, CSV, and XLSX work

## Slides

- Slide editing, themes, reorder, notes, presenter mode, images, and PPTX work

## Notes

- Search, notebook, tags, pinning, preview, automatic save, import, and export work

## Draw

- Shapes, text, selection, movement, deletion, colors, save, SVG, and PNG work

## Organizer

- Tasks, calendar events, and contacts persist locally

## Installer

- One Installed apps entry
- Start Menu shortcut and optional desktop shortcut
- EULA displayed
- Optional LeanDesk-native file associations
- Uninstall preserves user data

# LeanDesk Suite 0.8.0 — All-Modules Functional Preview

LeanDesk Suite now brings Writer, Sheets, Slides, Notes, Draw, Tasks, Calendar, and Contacts together under one local-first Windows suite and one installer.

## Highlights

- Writer ribbon cleanup and extensive offline spell checking
- 100,000+ word bundled English dictionary plus personal words
- Functional spreadsheet formulas with CSV/XLSX workflows
- Presentation themes, speaker notes, presenter mode, and PPTX workflows
- Markdown notes with preview, search, notebooks, and tags
- Drawing tools with SVG and PNG export
- Local task, calendar, and contact organization
- No account, cloud service, telemetry, or subscription

## Known notes

This is a functional preview intended for testing. Advanced Office-format compatibility, complex layouts, broad spreadsheet formulas, rich presentation objects, and professional vector-editing features remain later roadmap work.
